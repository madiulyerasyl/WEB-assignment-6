# Assignment 6 - jQuery

## Description
This project is my Assignment 6 for the Front-End Development course.

The goal is to practice jQuery selectors, effects, DOM manipulation, and animations.

## Technologies
- HTML
- CSS
- JavaScript
- jQuery

## Tasks
- Task 0: jQuery Setup
- Task 1: Selectors & CSS
- Task 2: Visibility Methods
- Task 3: Fade Methods
- Task 4: Slide Methods
- Task 5: Add & Remove Elements
- Task 6: Modifying Attributes
- Task 7: Form Interaction
- Task 8: Basic Animation
- Task 9: Sequential Animations
- Task 10: Combined Animation
- Task 11: Accordion Menu Mini Project

## How to Run
1. Download or clone the repository.
2. Open the project in VS Code.
3. Open index.html using Live Server.
4. Use the navigation bar to switch between tasks.

An internet connection is required to load jQuery from the CDN.
